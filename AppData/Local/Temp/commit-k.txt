feat(qr): permanent tokens + clean printable QR + skip geo prompt when disabled

QR rotation removed as a user-facing feature
- Migration flips the DB default for qr_rotates_every_seconds from 300 → 0
  and updates every existing row that still carries the old 300 default to
  0, so posters printed today keep working until the device row is deleted.
- Devices form: rotation window field is gone; formToPayload always sends 0.
- Row actions: "تدوير الرمز" icon removed (only view / edit / delete stay).
- QR modal: "تدوير الرمز الآن" button removed; caption spells it out:
  "الرمز دائم — لا ينتهي إلا عند حذف الجهاز".

Printable QR is truly QR-only now
- Old approach relied on print-media CSS to hide the rest of the page, but
  the browser still printed its own header (tab title, URL) and footer
  (date, page number) — the printout looked cluttered.
- New approach opens a fresh chrome-less window containing ONLY the QR
  SVG (grabbed off the live QRCodeSVG instance so no re-encoding), with
  `@page { margin: 0 }` stripping the browser header/footer entirely.
  window.print() fires on load, and afterprint auto-closes.

Scan flow no longer prompts for location on non-geo devices
- ScanController::deviceInfo now returns `enforce_geo` + `enforce_ip` so
  the kiosk knows the device's policy without a second round-trip.
- Kiosk scan page only invokes navigator.geolocation when
  device.enforce_geo === true — otherwise we skip the prompt and send
  null coords, which the FraudGuardService already accepts. Removes the
  spurious "enable location" dialog and the 10s denial timeout on
  devices where geo isn't enforced.
